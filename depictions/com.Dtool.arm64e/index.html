抖音 Dtools · Sileo 直装版

作者：Rookib

描述

主要功能

  • 提供抖音主页修复、访客数量设置、认证显示与专属 ID 自定义。
  • 本次适配抖音 41.2.0（412021），修复认证图标与文案、抖音号留白和二维码排布。
  • 小丑模式隐藏私密作品入口并收起原 60 点占位，关闭后恢复本人入口。
  • 使用 v16 基线，包含完整主插件、布局库、资源及已有铭牌样式功能。

适配范围

  • 本次新增适配抖音 41.2.0（构建 412021），支持自定义 Bundle ID。
  • 适用于 iOS 16.0 及以上的 RootHide 隐根环境，架构为 iphoneos-arm64e。
  • 包内同时保留抖音 40.7.0（407019）与 41.1.0（411016）的既有布局适配文件。

安装与使用

1. 在已有 RootHide 隐根环境的设备上，通过 Sileo 安装本包。

2. 先移除同一抖音 App 内旧的 Dtools 巨魔注入副本，避免重复加载；在 RootHide App List 中允许抖音注入。

3. 安装完成后彻底退出并重新打开抖音，在设置页进入 Dtools。
