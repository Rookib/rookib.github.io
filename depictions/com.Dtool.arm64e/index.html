抖音 Dtools · Sileo 直装版

作者：Rookib

描述

主要功能

  • 提供抖音主页修复、访客数量设置、认证显示与专属 ID 自定义，保留专属 ID 皇冠和原插件倍速功能。
  • 使用 v16 稳定程序，主插件、布局库及所需资源均已包含。
  • 本地功能不再依赖原授权服务器响应，保留本地文件完整性检查与账号切换清理。

适配范围

  • 适用于 iOS 16.0 及以上的 RootHide 隐根环境，软件包架构为 iphoneos-arm64e；普通 Rootless / Rootful 请勿安装本直装版。
  • 支持抖音自定义 Bundle ID；原生主页布局修复按已适配的宿主构建启用。本轮已验证抖音 41.1.0（411016），其他抖音/iOS 版本仍需适配验证。

安装与使用

1. 在已有 RootHide 隐根环境的设备上，通过 Sileo 安装本包。

2. 先移除同一抖音 App 内旧的 Dtools 巨魔注入副本，避免重复加载；在 RootHide App List 中允许抖音注入。

3. 安装完成后彻底退出并重新打开抖音，在设置页进入 Dtools。

验证情况

  • v16 两种加载方式已在 iPhone 14 Pro / iOS 16.0.2 / 抖音 41.1.0 完成断网冷启动与面板操作检查，未出现插件校验或授权异常。
  • 本次源内修订仅统一名称、作者、中文说明和详情地址；全部程序、资源及安装路径与已验证 v16 逐字节相同。
  • 注入版已验证 App 内三库运行；本轮未分别重做两种注入器的导入界面操作。联网资料刷新、媒体下载及 AI 接口仍需要网络和相应服务配置。
  • 不包含暂缓的直播礼物、财富等级及铭牌实验功能。顶部头像挂件的视觉显示仍有已知问题；抖音升级后可能需要继续适配。
