Touch-Dan

作者：Rookib

描述

主要功能

  • 显示屏幕触点和滑动轨迹，可选择仅在录屏期间显示。
  • 调节填充颜色、边框颜色、不透明度、填充大小、边框宽度与圆角半径。
  • 调节动画时长及抬起缩放，支持跟踪、笔刷、变形和图片效果。
  • 支持选择 Emoji 或自定义图片，并设置图片自动旋转。

界面与图标

  • 恢复 Touch-Viz 4.2 原版设置分组、按钮布局与中文标签。
  • 名称为 Touch-Dan，版本为 4.2，继续使用原版图标。
  • 保留上游许可与版权声明。

兼容性

  • 构建目标为 iOS 16.0 及以上，分别提供无根 Rootless 与隐根 RootHide 安装包。
  • 请按实际越狱环境选择安装包；无根包不能直接当作隐根包使用。
  • 本次 4.2 尚未完成 iOS 16/17 全部真机验证，模拟器界面核验不等同于真机注入验证。

资源存储

  • 隐根版资源与运行数据使用越狱隐根目录。
  • 保留 RootHide 路径保护，避免把插件资源写入系统 /var/tmp。
