RootHide SSH 提示静默

作者：Rookib

描述

主要功能

  • 仅隐藏 RootHide 管理器检测到 SSH Server 已安装时显示的卸载提示。
  • 精确匹配上游两种提示原文及当前语言对应译文，不影响其他检测警告。
  • 不修改 RootHide 黑名单、应用开关、SSH 服务或系统配置。

兼容性

  • 适用于 RootHide 隐根环境，最低系统版本为 iOS 15.0。
  • 仅加载到 RootHide Manager（com.roothide.manager），不注入 SpringBoard 或其他应用。
  • 针对 iOS 17.3.1 / Relaxin 环境制作；依赖管理器当前内部提示接口，管理器更新后可能失效，尚待真机验证。

使用说明

  • 安装后完全退出并重新打开 RootHide 管理器即可生效，没有设置页面。
  • 卸载后重新打开 RootHide 管理器，原提示会恢复。
  • 不需要为此更改 RootHide 黑名单设置。

重要说明

  • 本插件只让提示静默，SSH 服务仍保持原状态。
  • 隐藏提示不会提升 SSH 安全性；请修改默认密码、优先使用密钥认证并限制访问网络。
  • 不需要 SSH 时，请另外关闭或卸载 SSH Server。
